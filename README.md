# 游戏内生态系统与生物AI系统

## 项目描述

游戏内生态系统与生物AI系统的bug修复项目。核心模块 `world/ecosystem.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 生物AI只有简单随机移动没有觅食躲避繁殖
- 食物链只有狼吃兔子这一层
- 种群动态完全没做数量不会自然变化
- 迁徙完全没做动物永远在一个地方
- 生态平衡完全没做一个物种灭绝不影响其他

## 运行测试

```bash
python -m pytest tests/test_ecosystem.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
